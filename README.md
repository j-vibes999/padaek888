# ປາແດກ888 — ລະບົບບໍລິຫານຫຼັງບ້ານ (Pa Deak Operations)

ระบบหลังบ้านและการจัดส่งสำหรับ **ປາແດກ888 ກະປ໋ອງ 350 ml** (สินค้าเดียว, ค่าเริ่มต้น 12 กระป๋อง/แพ็ก — เปลี่ยนได้ในหน้าตั้งค่า) — ออเดอร์, ร้านค้า, สต็อก, OEM, ใบวางบิล และการเก็บเงิน

## เปิดใช้งาน

- **วิธีง่ายสุด:** ดับเบิลคลิก `index.html` เปิดใน Chrome / Safari / Edge ได้เลย
- **ผ่านเซิร์ฟเวอร์ในเครื่อง:** `npm install` แล้ว `npm run dev` → เปิด http://localhost:4173
- ต้องมีอินเทอร์เน็ตเฉพาะ **แผนที่** (Leaflet + แผนที่ถนน/ดาวเทียมจาก Esri — เปิดไฟล์จากเครื่องตรง ๆ ได้) และฟอนต์ Noto Sans Lao — ถ้าออฟไลน์ ส่วนอื่นยังใช้ได้ปกติ

## ทดสอบ

```bash
npm test
```

เทสต์จะโหลดโค้ดจริงจาก `index.html` (`<script id="pa-deak-domain">`) มารัน — ไม่ได้ก๊อปฟังก์ชันมาเขียนซ้ำ จึงจับบั๊กในแอปได้จริง (ต้องใช้ Node 18 ขึ้นไป ไม่ต้องติดตั้งอะไรเพิ่ม)

## ⚠️ ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมดอยู่ใน **localStorage ของ browser เครื่องที่เปิดใช้งาน** เท่านั้น

- ถ้าล้างประวัติ browser, ใช้โหมดไม่ระบุตัวตน หรือเปลี่ยนเครื่อง → ข้อมูลไม่ตามไปด้วย
- **ดาวน์โหลดไฟล์สำรอง JSON เป็นประจำ** (หน้า ⚙ ຕັ້ງຄ່າ) — ระบบจะแจ้งเตือนถ้าไม่ได้สำรองเกิน 7 วัน
- ฝ่ายการตลาดกับฝ่ายจัดส่ง **ยังใช้ข้อมูลชุดเดียวกันข้ามเครื่องไม่ได้** ถ้าต้องการต้องเพิ่มฐานข้อมูลกลาง (เช่น Supabase / Firebase) — ดู `docs/CHANGELOG.md` หัวข้อ "สิ่งที่ยังไม่ได้ทำ"

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | แอปทั้งหมด (HTML + CSS + JS ในไฟล์เดียว) |
| ↳ `<script id="pa-deak-domain">` | กฎธุรกิจล้วน ๆ (ไม่มี DOM): สต็อก, ออเดอร์, ใบวางบิล, การจ่ายเงิน, รหัส, วันที่, migration — เทสต์ใช้ส่วนนี้ |
| ↳ `<script id="pa-deak-app">` | ส่วนแสดงผลและปุ่มต่าง ๆ (เรียกใช้ domain) |
| `tests/domain.test.js` | unit tests (node:test) |
| `PRODUCT.md`, `DESIGN.md` | ขอบเขตผลิตภัณฑ์และระบบสี |
| `docs/CHANGELOG.md` | รายการแก้ไขทั้งหมด |
| `docs/archive/` | แผนงานเก่าที่ไม่ตรงกับโปรเจกต์ปัจจุบัน (เก็บไว้อ้างอิง) |

## กฎธุรกิจหลัก (schema v3)

- **สต็อก:** ตัดออกจากสาง ตอนออเดอร์เป็น "ກຳລັງສົ່ງ" (ของออกจากสาง) — ถ้าของไม่พอ ระบบไม่ให้ปล่อยออเดอร์ · "สต็อกว่าง" = ในสาง − ออเดอร์ที่รอแพ็ก/กำลังแพ็ก · แก้ตัวเลขสต็อกได้ทางเดียวคือ "ປັບສະຕັອກ" (ต้องเลือกเหตุผล ทุกครั้งมีประวัติ)
- **ใบวางบิล:** สร้างอัตโนมัติตอน "ສົ່ງສຳເລັດ" มีวันที่จริง และกำหนดชำระ = วันส่ง + วันเครดิตของร้าน (COD = วันเดียวกัน) · สถานะเกินกำหนดคำนวณจากวันที่
- **การจ่ายเงิน:** เก็บเป็นรายการ (`payments[]`) จ่ายหลายงวดได้ ยอดบิลเดิมไม่ถูกเขียนทับ
- **ยอดค้างของร้าน:** คำนวณจากใบวางบิลที่ยังค้างเสมอ (แก้มือไม่ได้) → ตัวเลขทุกหน้าตรงกัน
- **ร้านค้า:** อ้างอิงด้วยรหัส (`storeId`) ไม่ใช่ชื่อ — เปลี่ยนชื่อร้านได้โดยประวัติไม่หาย
- **รหัส (ORD / INV / ST / PO / ADJ):** ไม่ซ้ำและไม่ถูกนำกลับมาใช้แม้ลบรายการไปแล้ว
- ข้อมูลเก่า (v2) ในเครื่องจะถูกแปลงอัตโนมัติครั้งแรกที่เปิด และเก็บสำเนาเดิมไว้ใน localStorage key `pa_deak_ops_v2_350ml__backup_v2`
